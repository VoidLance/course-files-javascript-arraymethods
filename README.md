# JavaScript Array Methods Demo

A small browser-based interactive demo for practicing common JavaScript array methods. Add, remove, sort, reverse, and clear string values, then see the array update on the page.

## Why use this project?

- Practice `push`, `unshift`, `pop`, `shift`, and `splice` through interactive controls.
- See array contents and their positions update immediately.
- Explore `sort` and `reverse` without installing libraries or setting up a build process.

## Get started

This project has no external dependencies or build step.

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.
3. Enter a value and use the buttons to modify the array. Use the index field with **Remove by Index (splice)** to remove an item at a specific position.

For example, adding `pear`, then `apple`, and choosing **Sort** displays the values in sorted order. The demo sorts strings using JavaScript's default `Array.prototype.sort()` behavior.

The main files are `index.html` (the page and controls) and `script.js` (the array operations and display logic).
